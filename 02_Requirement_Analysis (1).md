# PHASE 2 – REQUIREMENT ANALYSIS
## Project Name: EduGenie AI – Google Gemini Powered Learning Assistant

### 1. Functional Requirements
- The system shall accept a user's educational question or text.
- The system shall generate answers using an AI model.
- The system shall explain concepts in simple language.
- The system shall generate multiple-choice quizzes.
- The system shall summarize lengthy educational passages.
- The system shall generate structured learning recommendations.
- The system shall display the generated result through the web interface.
- The backend shall provide separate endpoints for major learning functions.

### 2. Non-Functional Requirements
- User-friendly interface
- Fast and reliable request handling
- Modular and maintainable code
- Secure API-key handling
- Error handling for invalid requests and API failures
- Ability to extend the system with additional learning features

### 3. Hardware Requirements
- Laptop or desktop computer
- Minimum 4 GB RAM recommended
- Internet connection for cloud AI requests

### 4. Software Requirements
- Python 3.10 or later
- FastAPI
- Uvicorn
- Jinja2
- HTML5
- CSS3
- Google Gemini API
- Modern web browser

### 5. User Requirements
The user should be able to:
1. Open EduGenie AI.
2. Select a learning task.
3. Enter a question, topic, or passage.
4. Submit the request.
5. View the AI-generated response.

### 6. API Requirements
The application requires a Google Gemini API key. The key should be stored securely using an environment variable and should not be uploaded to GitHub.

### 7. Phase Conclusion
All major functional, non-functional, hardware, software, user, and API requirements were identified for EduGenie AI.
